🔎 Como funciona?

O que acontece ao enviar o formulário?

Como este projeto foi desenvolvido somente com HTML, o formulário possui finalidade demonstrativa e acadêmica. Ele não envia os dados para um banco de dados.


Por que existem campos obrigatórios?

O atributo required informa ao navegador que determinados campos precisam ser preenchidos antes do envio.


Para que serve o datalist?

O elemento <datalist> fornece sugestões enquanto o usuário preenche um campo de texto.

🕷️ Uma nova experiência

Assim como Peter Parker enfrenta novas fases em sua jornada, este formulário representa uma nova forma de interação dentro do projeto.

Um novo dia também pode ser uma nova experiência.
