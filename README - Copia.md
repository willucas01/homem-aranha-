# 🕷️ Homem-Aranha: Um Novo Dia

## 📚 Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de HTML Avançado.

O objetivo é apresentar um site sobre o filme **Homem-Aranha: Um Novo Dia**, abordando sua história, personagens, mudanças, conflitos, lições, curiosidades e elementos cinematográficos.

O projeto também utiliza recursos avançados do HTML5, incluindo formulários, tabelas, elementos semânticos, multimídia e elementos interativos.

---

## 🎯 Objetivos

* Desenvolver um site utilizando HTML5.
* Aplicar estrutura semântica nas páginas.
* Utilizar tabelas e listas.
* Trabalhar com imagens, áudio e vídeo.
* Criar um formulário avançado.
* Utilizar elementos interativos do HTML5.
* Utilizar diferentes tipos de campos de formulário.
* Organizar corretamente os arquivos do projeto.
* Criar uma navegação funcional entre as páginas.

## ▶️ Como executar

O projeto pode ser executado utilizando um navegador.

Uma forma recomendada é utilizar a extensão **Live Server** no Visual Studio Code.

### Passos:

1. Abra a pasta `HOMEM-ARANHA` no Visual Studio Code.
2. Localize o arquivo `index.html`.
3. Clique com o botão direito sobre ele.
4. Selecione **Open with Live Server**.
5. O projeto será aberto no navegador.
6. Utilize o menu de navegação para acessar as demais páginas.
